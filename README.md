## 🛠️ الأجهزة والمهارات المساحية
- **جهاز الميزان (Level):** مستوى متقدم (ضبط مناسيب الحفر والردم، الميزانيات الطولية والعرضية والشبكية).
- **أجهزة الـ GPS (GNSS):** مستوى جيد (تحديد الإحداثيات والرفع المساحي والربط بالشبكات).
- **جهاز التوتال ستيشن (Total Station):** توقيع النقاط الثابتة ومحاور الطرق والمنشآت.
- **نظم المعلومات الجغرافية (GIS):** تحويل القياسات الحقلية والمخططات إلى خرائط رقمية دقيقة.
- **اللغة الإنجليزية:** جيد (إلمام كامل بالمصطلحات الهندسية والمساحية).

## 🏗️ أبرز المشروعات الميدانية
1. **مشروع تغطية ترعة الكوبري البسيوني:** إنشاء طريق يربط بين الدائري والمدينة وضبط مناسيب المجرى المائي والردم.
2. **مشروع توسعة وإعادة رصف طريق قرية قسطا:** ميزانيات تفصيلية لطبقات الأساس وضبط مناسيب وميول الرصف.
3. **مشروع رفع كفاءة طريق كفر الزيات – لاندسكيب:** توقيع البردورات والجزر الوسطى ومناسيب المساحات الخضراء.
4. **أعمال مساحية وطبوغرافية بجبل سانت كاترين (جنوب سيناء):** توقيع حدود ومناطق في تضاريس جبلية وعرة وتحويلها لخرائط.
